# Tech Lab 2주차 (2D World to 3D World)

## 🎮 2D World to 3D World

**제작 기간**: 2026.09.04 ~ 2026.09.10 (7일)

**작업깃허브** : https://github.com/Kimyoungkyun-jg/week2team2/commits/main/


## ✨ 주요 기능

- 2D에서 3D 공간 확장
- 씬 저장, 읽기 기능 
- Picking 기능
- 기즈모, 속성을 통해 프리미티브 변형 가능 
- 카메라 이동 가능 
- UObject 구현 

## 👥 담당
- 카메라 시스템 (카메라 클래스 설계, 원근 투영, 직교 투영 구현)
- 레이캐스팅 기반 오브젝트 피킹 시스템 구현 (뮐러-트럼보어 알고리즘 사용)
- 카메라 거리에 따라 두께가 보정되는 셰이더 기반 아웃라인 하이라이트 구현
- 프레임 상수 버퍼 도입으로 카메라 행렬 갱신 프레임 당 1회로 최적화
- 모듈별 디렉터리 구조로 재배치
