## ✨ 주요 기능

- 텍스처 아틀라스 구현
- 텍스쳐 맵핑과 uv좌표계, vs texture sampler 이해
- Sprite (Billboard) 렌더링 구현, Screen-Aligned Quad 렌더링 
- Batch Line 렌더링
- Index Buffer 사용
- 프리미티브의 Bounding Box(AABB) 계산, 렌더링
- 씬안에 배치되어 있는 오브젝트들을 관리할 수 있는 Scene Manager 구현

- Batch Line 렌더링 구현
- AABB 디버그 박스를 인덱스 버퍼 기반 배치 라인 렌더링으로 전환
